# Kwetu Raha — concept prototype

Responsive dark red and black East African directory concept.

## Files
- index.html — homepage and sample cards
- styles.css — responsive styling
- script.js — demo age gate, mobile menu and filters

Open index.html in a browser to preview.

## Important
This is a front-end prototype only. The age gate is not reliable age verification. There are no real accounts, listing storage, image uploads, payments or admin dashboard. Sample cards are fictional placeholders. Do not publish real profiles or collect sensitive information with this prototype.

Before accepting real listings, implement secure age and identity checks, documented consent and image rights, human moderation, reporting/takedown workflows, privacy protections and country-by-country legal review. Never permit minors, coercion, trafficking, exploitation, impersonation or non-consensual material.
